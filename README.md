# Firestone

Firestone is a daemonless Linux x86_64 VM manager built on Cloud Hypervisor. Start with the [user guide](docs/user-guide.md). The v0.1 design and acceptance criteria live in [SPEC.md](SPEC.md).

The project is in the M5 Linux MVP milestone. See [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md) for the active work queue, verified behavior, and open KVM gates.
